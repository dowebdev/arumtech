# ADR-0002 — SE 원본 1페이지 = 1제품 카드 (WP 변형 분리)

- 상태: 채택 (Accepted)
- 날짜: 2026-07-23
- 관계: [ADR-0001](0001-se-product-content-source.md) 의 결과 일부를 수정한다.

## 배경 (Context)

ADR-0001 로 방수 동축 2종(`COX-8 WP` / `COX-12 WP`)을 추가하면서, 기존 비방수
`COX-8 mk2 / COX-12 mk2` 처럼 **한 카드(2열 사양표)** 로 묶어 `cox-8-cox-12-wp` 슬러그
하나로 넣었다.

그러나 SE 본사 사이트(se-audiotechnik.de)에서 두 모델은 **각각 독립된 제품 페이지**다.

- https://se-audiotechnik.de/produkt/cox-8-wp-2/
- https://se-audiotechnik.de/produkt/cox-12-wp-2/

두 제품은 태그라인·소개문·주파수 특성·트랜스듀서·치수·중량이 모두 다르다. 이를 2열로
묶으면 각 모델 고유의 카피(예: COX 8 "Tuned for clarity" vs COX 12 "Natural detail…")를
살릴 수 없고, 출처 URL도 한쪽만 기록된다.

## 결정 (Decision)

**SE 원본에서 페이지가 분리돼 있는 제품은 사이트에서도 각각 독립 카드(별도 slug)로 둔다.**
WP(방수) 변형은 대응하는 비방수 모델과 묶지 않는다.

- `cox-8-cox-12-wp` 합침 카드를 폐기하고 `cox-8-wp`, `cox-12-wp` 두 카드로 분리했다.
- 각 카드는 자기 페이지의 태그라인·소개·특징·사양·부속·이미지·`sourceUrl` 을 갖는다.
- `specColumns` 2열 묶음(`v` 배열 길이 > 1)은 **원본이 실제로 한 페이지에서 여러 모델을
  열로 나열할 때만** 쓴다 (예: 기존 `COX-8 mk2 / COX-12 mk2`, `B-18 / B-18A`).

같은 맥락에서 `M-F3A PRO MAX` 는 SE 단독 페이지가 존재하므로, 외부 링크 라인 탭에서
내부 실제 상품(`m-f3a-pro-max`, 플래그십 단독 라인)으로 전환했다.

## 결과 (Consequences)

- ADR-0001 "결과"의 *"두 방수 동축 모델을 한 카드로 묶었다"* 항목은 이 ADR로 **무효**가 된다.
- 기존 비방수 합침 카드(`cox-8-cox-12` mk2, `b-18` = B-18/B-18A)는 **손대지 않는다.**
  원본이 한 페이지에서 여러 모델을 열로 제시하는 형태이거나, 이번 작업 범위 밖이기 때문이다.
- 이후 SE 가 신규 변형을 별도 페이지로 내면 기본값은 **분리(별도 slug)** 다.
